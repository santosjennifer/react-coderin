### Como executar:

- Dentro do repositório do backend:

Para instalar as dependências:
```
npm install
```

Para iniciar o projeto:
```
npm run server
```

- Dentro do reposiório do frontend:

Para instalar as dependências:
```
npm install
```

Para iniciar o projeto:
```
npm run start
```
**Observação:** Configure as environments de acordo com seu ambiente.
